# privy

Personal portfolio website for Darshan Mehta.

## 🌐 Website

This repository contains a modern, responsive personal portfolio website featuring:

- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Modern Styling**: Gradient background with card-based design
- **SEO Optimized**: Includes meta tags for search engines and social media
- **Accessible**: Semantic HTML with descriptive alt text and proper structure
- **Secure**: External links use proper security attributes

## 📋 Sections

- **About**: Introduction and profile information
- **Projects**: Featured projects and work
- **Contact**: Ways to get in touch

## 🚀 Deployment

This website is designed to be deployed via GitHub Pages. Simply enable GitHub Pages in the repository settings to make it live.

## 🛠️ Technologies

- HTML5 with semantic elements
- CSS3 with flexbox and gradients
- Google Fonts (Montserrat)
- Responsive design with media queries
